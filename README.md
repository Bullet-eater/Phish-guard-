## 🔥 Features

PhishGuard is an ALL-IN-ONE security tool that protects against:

- 🦠 **Malware/Viruses/Worms** - Real-time scanning and neutralization
- 🎣 **Phishing Attacks** - Detects malicious links and domains
- 📹 **Webcam Hijacking** - Monitors unauthorized camera access
- 🌊 **DDoS/DoS Attacks** - Connection tracking and IP blocking
- 📡 **CCTV Vulnerabilities** - Scans for exposed cameras
- ⚡ **Flipper Zero Attacks** - Detects BadUSB, RF, and NFC attacks
